# 正文关联批注验收

日期：2026-11-25。运行时：`2026-11-25-v9`。入口：[完整单文件模板](../offline-report.html)。设计约束见[PRD](设计方案.md)与[批注设计](批注设计.md)。

## 测试对象与方法

使用桌面 Chrome 打开完整 HTML，包含目录、正文、工具栏、双栏和批注系统。内容全部为通用模板，不使用研究文档。通过真实界面创建两条批注、填写署名并回复两次，与模板原有批注组成三条测试线程。

锚点、模式、回复和解决状态由实际界面操作生成；排错后将这些测试数据载入完整的新运行时继续复测，未使用独立组件预览代替完整页面。测试数据仅存在于临时副本，仓库主模板仍为一条演示批注。

最终主模板为 150,209 B，SHA-256：`df21facbadd08d775dd7cd84a5a6e57a95ebcf9be85a003ef0c47c8ddc207795`。

## 保存与重新打开

通过实际文件菜单导出测试 HTML，读取磁盘产物，再在新标签打开该文件内容。实际产物为 152,818 B，SHA-256：`e91ee169f566ace51c8be4decda42874f91c2be9e7681071c72a5bbf1d0208bb`。

重开后核对：

- JSON 为版本 4，保留 `list` 模式和“记录者”署名。
- 三条线程作者依次为模板作者、讨论者、记录者，留言数为 1／3／1。
- 两条失联批注保留原文、意见及回复；第三条已重新绑定至概览，锚点偏移为 5，并保留一份历史。
- 第三条解决状态与删除线保留；替换后的正文、双栏和折叠组件仍在。

导出与重开使用的运行时与最终主模板相比，仅缺少最后补充的未提交编辑离开提醒和选区保护；序列化及写回算法相同。最终主模板另行通过脚本检查与空白文件生成复测。

**这轮验证的是导出文件后重新打开，不是原文件授权写回。**当前工具拒绝 `file://`，没有重跑 v9 原文件授权写回或整个浏览器进程重启。历史 v5 写回证据按版本保留在[完整 HTML 回归](完整HTML回归.md)，不作为 v9 写回验收。

## 逻辑检查

```sh
node scripts/check_annotation_logic.mjs
python3 scripts/check_saved_report.py offline-report.html
```

16 项逻辑检查全部通过，覆盖：稳定偏移、重复引文的上下文判定、歧义拒绝、过期偏移、选区前后及内部编辑、首尾字符改写、emoji 的 UTF-16 偏移、保留引文的整段变化、删除失联、仅共同标点不得恢复、明确整段选区替换，以及避让间距和顺序。三段可执行内联脚本通过 Node 语法检查。

磁盘检查仅证明模板结构与内容完整，不能代替浏览器交互。浏览器日志中出现过翻译扩展自身错误，未将该错误归入模板页面；空白模板新开标签未记录页面错误。
