# 完整 HTML 的模板回归记录

日期：2026-11-25。当前运行时标识：`2026-11-25-v6`。测试内容统一使用通用模板，不使用具体研究文档。

## 测试对象与生成方式

通过 `offline-report.html` 的文件菜单选择“创建空白模板”，得到背景与问题、概览、方案设计、验证与证据、讨论、总结六个主题。通过页面真实编辑入口填入通用文字，在首个主题插入双栏和折叠补充，并对一段正文添加“请保留”批注。随后通过“导出 HTML 副本”生成文件，重新打开该导出文件核对内容。

可复现文件为 [examples/template-demo.html](../examples/template-demo.html)，不是拆出的组件预览。截图来自该完整 HTML 的实际页面，包括目录、正文、汇报工具栏和批注栏。

正文示例为“把一份文档，变成可讲、可改、可讨论的汇报。”；批注为“请保留这句结论。示例内容可以替换成自己的项目。”。截图只展示模板能力，不包含研究结论。

## 原文件写回与媒体的既有证据

2026-11-25 较早一轮对 v5 完整 HTML 做过桌面 Chrome 原生文件选择与写入授权，直接修改同一磁盘 HTML，关闭标签后重开。已核对正文、已编辑批注、意图、双栏和内嵌 GIF 数据保留，并核对含 `<保留> &` 的批注未损坏。相关记录保留在 [PR #1](https://github.com/CherryYang05/offline-html/pull/1) 对应版本中。

GIF 的既有浏览器检查覆盖插入、解码显示、展开／关闭清除 src，以及保存后资源保留；这不单独证明所有帧已经视觉验收。真实多帧播放仍需按 PRD 的 AC-10 补齐证据。本轮通用模板示例不包含 GIF，不伪造相关截图。

v6 仅调整空白模板初始化的可选元素访问和通用标签，没有改动写回算法。本轮未重跑 v6 的原文件授权写回；历史结果按版本引用，不替代新版本验收。

## 打开方式与覆盖边界

测试由本机 HTTP 提供完整文件。当前工具拒绝直接访问 `file://`，因此没有完成双击 HTML 的实际权限验收。本机 HTTP 只是测试入口，HTML 没有服务器依赖。

仍未覆盖：本地双击路径、整个 Chrome 进程重启、Edge／Safari／Firefox、移动设备实机、权限撤销和磁盘冲突的完整真实操作矩阵。320／390 像素是桌面浏览器视口检查，不等同于手机实机测试。
