# 完整 HTML 的 Chrome 回归记录

日期：2026-11-25。被测版本：`549f09b`，HTML 修订标识 `2026-11-25-v5`。

本轮测试完整的 `offline-report.html`，包括所有正文、目录、图表、编辑器、批注栏和文件写回逻辑。没有使用组件预览或模拟文件句柄。未发现需要追加修复的模板功能问题，因此本轮提交仅补充回归记录、截图和磁盘核对脚本。

## 实际测试路径

将仓库 HTML 复制成测试副本，由 `127.0.0.1` 的临时 HTTP 服务提供。Chrome 通过原生文件选择器选择**同一份被提供的磁盘 HTML**，点击允许写入。点击保存入口后，检查磁盘文件实际内容，而非只看页面的“已保存”提示。关闭标签后新建标签，重新读取该磁盘 HTML。

当前自动化工具拒绝直接访问 `file://`。本轮验证了实际文件选择、原文件写回和从磁盘重开，但没有验证双击 HTML 打开时的浏览器权限行为。本机 HTTP 是测试入口，模板没有增加服务器、联网资源或缓存依赖。未重启整个 Chrome 进程，也未覆盖 Edge、Safari、Firefox 和移动设备。

## 可复查的磁盘验收

需要复跑时，在测试副本中设置下列文字，并完成真实授权、写回、关闭及重开：

- 正文：`完整 HTML 实测正文：2026-11-25，关闭重开后保留。`
- 选中该句新建一条批注，意图为“请保留”；重开后将批注改为：`重开后再次编辑成功：<保留> & 正文、双栏与 GIF。`
- 插入一个双栏，左栏：`左栏持久化：原始规则和证据。`；右栏：`右栏持久化：修正后的预测与解释。`
- 插入一个本地 GIF，完成播放／停止、写回及重开。

然后运行：

```sh
python3 scripts/check_saved_report.py /绝对路径/测试副本.html
```

脚本只读检查保存产物，不能代替浏览器授权、布局观察或真实关闭重开。本轮输出：

```json
{
  "passed": true,
  "bytes": 216883,
  "sha256": "c031f0be1772100220ac4030ed132f0c11287d128d5b6d088c63cf012e7d7dd6",
  "threads": 1,
  "components": ["columns", "image"],
  "gif_bytes": 12371
}
```

新一轮的 UUID、时间戳和 GIF 不同，文件大小与哈希会变化。判据是正文、批注、锚点和媒体数据保留。脚本对未操作的干净模板会返回失败，避免把原始模板误当成写回成功。测试副本留在临时目录，没有混入公开模板。
