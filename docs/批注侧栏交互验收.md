# 批注侧栏交互验收

日期：2026-11-25。版本：`2026-11-25-v8`。环境：本机 macOS、桌面 Chrome，HTTP 提供完整 `offline-report.html`。全部截图使用通用模板内容。

## 1. 桌面外框与内部层级：通过

打开汇报模式与批注，核对目录、当前正文卡片和批注侧栏：三者外框圆角均为 6 px，目录与批注侧栏顶部同为 74 px。批注使用一个固定白色容器；内部留言没有独立圆角、边框或阴影，引用只有左竖线，不再叠底色卡片。

编辑、回复、删除、导出与引用跳转均使用 `#245da8` 蓝色及下划线；悬停时加深，键盘聚焦仍有轮廓。选中的留言使用左侧细线提示。

![桌面批注抽屉](https://github.com/user-attachments/assets/c6a27d0f-a5ae-418c-90d3-3b7b0855d375)

## 2. 完成、重开与表单：通过

- 勾选“已完成”后，留言正文显示 `line-through`；取消勾选后恢复 `none`。原文引用保留蓝色跳转提示。
- 待处理筛选在完成后显示空状态，全部筛选仍能找到该批注；完成／重开后焦点回到复选框或筛选按钮。
- 实际打开编辑、保存、回复及新增批注表单，取消操作可恢复原内容。引用跳转仍能定位正文并选中对应留言。
- 将完成状态导出为 HTML 副本，在新标签重开：内嵌数据 `resolved: true`、勾选状态与删除线一致。此项是导出副本验收，不等同于原文件授权写回。

![完成状态与删除线](https://github.com/user-attachments/assets/350a8c88-0732-43d9-a5aa-104b0ebc8409)

## 3. 开关、窄屏及滚动：通过

- 侧栏与目录共用 180 ms 的滑动／淡入淡出时长；快速关闭再打开不会被旧定时器隐藏。关闭期间不可交互，动画完成后隐藏。
- 实测 Escape 关闭并回焦点，点击窄屏遮罩关闭，再打开可继续操作。
- 390 × 844、320 × 760 下外框圆角统一为 4 px，整页滚动宽度分别为 390、320 px；正文双栏按顺序堆叠。
- 320 px 下编辑表单的“取消”“保存批注”均在视口内；长批注使侧栏内部滚动，不撑宽整页。
- 修改后恢复浏览器视口。关闭侧栏的截图等待其真正隐藏后采集，未使用过渡中的画面。

## 4. 模板与代码核对：通过

- 从文件菜单实际生成并下载空白模板，再在新标签打开：六个主题保留、批注为空，新版侧栏显示可操作的空状态。
- 主模板与生成文件的三段可执行脚本通过语法检查；主模板内容核对脚本通过，空白文件负例返回失败。
- 主模板、完成状态导出副本及空白模板的浏览器日志均无 error / warn。
- 侧栏使用 CSS 排布与独立滚动；不再通过逐条批注测量、绝对定位来排列留言。

## 验收边界

写回算法和批注数据格式没有改变，本轮没有重跑原文件授权写回、权限撤销与磁盘冲突测试。历史结果及其他浏览器、`file://`、GIF 多帧播放的未覆盖项见[完整 HTML 回归记录](完整HTML回归.md)。减少动态效果的媒体规则及即时关闭分支已做静态核对，未更改系统偏好做实机切换。
