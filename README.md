# offline-html
可编辑、可批注的单文件离线汇报模板，用于替代 PPT 展示文档、媒体与交互组件。

下载 [`offline-report.html`](offline-report.html)，用桌面浏览器打开即可离线使用。

- 点击「汇报模式」切换章节，点击「编辑正文」原位修改或插入内容。
- 选中正文可批注、回复，并标记「建议修改」「请保留」或「讨论」。
- 使用支持原文件写回的桌面 Chrome 或 Edge 时，点击「连接原文件」，选择这份 HTML 并授权。顶栏显示保存状态。
- 从文件菜单可创建空白模板。完整说明见[设计方案](docs/设计方案.md)。

当前通用模板已核对汇报内编辑、批注、双栏、折叠补充、导出后重开与窄屏布局。历史原文件写回测试按版本记录；GIF 多帧播放和其他环境仍待验收，详见[回归记录](docs/完整HTML回归.md)。

`offline-report.html` 是唯一模板入口，预填六个通用主题、双栏、折叠补充和一条演示批注。可直接替换内容；需要清空内容时，从文件菜单选择“创建空白模板”。
