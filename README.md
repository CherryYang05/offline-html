# offline-html

可编辑、可批注的单文件离线汇报模板，用于展示文档、表格、媒体和交互组件。

下载 [offline-report.html](offline-report.html)，用桌面浏览器打开。文件预填六个通用主题、双栏、折叠补充和一条演示批注。文件菜单可创建空白模板。

- 点击「汇报模式」按主题讲解。阅读与汇报都可点击「编辑正文」修改原文或插入组件。
- 选中文字后，用浮动按钮或 Ctrl／⌘ + Alt + M 批注。桌面可切换「集中列表」和「随正文排列」，两种排列都支持按当前章节或全文查阅。批注直接填写意图和内容，解决与删除在卡片上操作。侧栏「导出」提供 Markdown 清单和 AI 修订指令 JSON。
- 插入菜单提供段落、双栏、折叠内容、页签、表格、图片／GIF／视频和条形图。媒体随 HTML 内嵌。
- 在支持原文件写回的桌面浏览器中，点击「连接原文件」，选择当前这份 HTML 并允许写入。等待顶栏显示「已保存」后即可关闭。受限环境可从文件菜单导出副本。
